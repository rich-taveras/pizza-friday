# Pizza Friday — Sourdough Micro Pizza

One-page website for Rich's home micro-pizza project (working name: **Pizza Friday**), Chantilly, VA.

The concept: 48-hour sourdough pizza (part whole wheat, same starter as the bread project), baked one day a week in small pre-ordered batches, with a rotating Latin-rooted monthly special. Status shown honestly on the page: **test kitchen, not taking orders yet** (selling hot pizza requires health permits in Virginia — it does not fall under the cottage-food law that covers the bread).

## Files

- `index.html` — the whole site (HTML + CSS + JS in one file). Open it in any browser.
